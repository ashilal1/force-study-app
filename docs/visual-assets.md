# 画像素材の一覧（称号・ランク・ランクで変わる見た目・期間限定のテーマ）

M11（F13 称号・F14 ランク）で使う画像。オーナーが用意して、下のパスに置く。届くまではアプリが CSS・SVG の仮の絵を出し、置いたら `src/lib/standing/assets.ts` の一覧に足すと差し替わる。

## 共通のルール
- **背景は透過**（PNG）。
- **大きさは表示の 2〜3 倍**で作る（スマホの高解像度の画面でぼやけないように）。下の「サイズ」はその値。
- **1 枚 200KB 以下**を目安に（スマホで読み込みが重くならないように）。
- **文字は入れない**（「WANTED」などの文字は、アプリが CSS で重ねる。称号の名前も同じ）。
- 白い背景でも、灰色のコンクリートの上でも見えるように、外側にうすい影か縁取りを付けると良い。

## 3. 期間限定のテーマの素材（`public/theme/<テーマ>/`）

期間限定のテーマ（F16・ADR-046）は、Claude Design の `Theme Picker v4` を CSS（`src/app/ui-themes.css`）と背景の飾り（`src/components/theme/ui-theme-layer.tsx`）に移したもの。**画像がなくても全部のテーマが動く**（かぼちゃ・ヒイラギ・水引などは CSS と SVG の仮の絵）。下の画像が届いたら、仮の絵と差し替える。共通のルール（透過 PNG・表示の 2〜3 倍・文字なし）は上と同じで、**1 枚 100KB 以下**にする。小さく出すものは太い線・はっきりした形にする。

まだ仕上げの途中で、本番には出していない（テスト用 URL と開発用の画面だけ）。急ぐ順: ハロウィン → クリスマス → お正月。

## いま入っているもの
2026-10-20 に、バッジ 26 枚（ランク 5・称号 21）とサイレン・柵を Gemini で作って入れた。太い黒の線と白いフチのステッカー風で、マゼンタ一色の背景で作り、背景を抜いて 512×512（サイレンは 256×256）・1 枚 50KB 以下にしている。描き直したものは同じファイル名で置き換えればよい。

作るときの指示（共通部分）: 「flat vector sticker illustration, thick black outlines, white sticker border, bold simple shapes. It must stay recognizable when shown at 24 pixels, so the main motif is LARGE … Absolutely no text … Background: one solid flat pure magenta color (#FF00FF) … Do not use magenta, pink or purple in the badge itself.」に、モチーフと色（悪い称号は赤・灰、良い称号は金・ミントグリーン）を足す。

## 画像がないとき
`assets.ts` の一覧にないものは、アプリが仮の絵を出す（称号は文字だけ、サイレンと柵は SVG・CSS）。
