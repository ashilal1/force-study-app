# 画像素材の一覧（称号・ランク・ランクで変わる見た目）

M11（F13 称号・F14 ランク）で使う画像。オーナーが用意して、下のパスに置く。届くまではアプリが CSS・SVG の仮の絵を出し、置いたら `src/lib/standing/assets.ts` の一覧に足すと差し替わる。

## 共通のルール
- **背景は透過**（PNG）。背景のタイル（`concrete.webp`）だけは不透明の WebP。
- **大きさは表示の 2〜3 倍**で作る（スマホの高解像度の画面でぼやけないように）。下の「サイズ」はその値。
- **1 枚 200KB 以下**を目安に（スマホで読み込みが重くならないように）。背景のタイルは 150KB 以下。
- **文字は入れない**（「WANTED」などの文字は、アプリが CSS で重ねる。称号の名前も同じ）。例外は `or-penalty.png` だけ。
- 白い背景でも、灰色のコンクリートの上でも見えるように、外側にうすい影か縁取りを付けると良い。

- 表示は名前の横で幅 20〜28px、プロフィールで幅 64px。**小さくても見分けられる、太い線・はっきりした形**にする。

## 届くまで
画像がないものは、アプリが仮の絵を出す（称号は頭文字と色の丸、王冠は SVG、背景は CSS の模様）。差し替えたら見た目を確かめるので、置いたことを教えてください。
