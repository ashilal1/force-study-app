# 選ばれたデザイン（2026-10-16 オーナー承認「いいね」）

完成予想図: `mockup.png`（round-02）。元になったオーナーの参考画像: `reference.jpg`。
`mockup.html` は見た目の確認用の使い捨て。**実装はこの HTML をコピーせず、画像を見て作る。**

## 空気感
クラシックでおしゃれ、かつ遊び心。紙の上にステッカーを貼ったような「ネオブルータル × 文房具」。

|---|---|---|
| 紙（背景） | `#f4efe8` | 画面の地 |

## 書体（すべて Google Fonts）
- 英字見出し: **Archivo Black**（COMMIT OR TREAT / TODAY'S MISSIONS / 大きな数字）
- 和文見出し・スタンプ: **Dela Gothic One**（大きめのサイズだけ。小さい見出しは本文の 900）
- 本文: **Zen Kaku Gothic New**（500 / 700 / 900）
- レシート: **BIZ UDGothic** 700（等幅で数字がそろう）
- 手書き: **Klee One** 600（合言葉、写真の中の文字）
- 合成の太字は使わない（`font-synthesis: none`）

## 形
- 箱: 白地 + 3px の黒い輪郭 + 角丸 14px + **右下 6px の黒いずらし影（ぼかしなし）**
- ボタン: 箱と同じ作りで影 5px。押したら影が消えて 5px 沈む
- ピル: 黒地に白文字のタグ / 白地に黒枠の小さいタグ
- スタンプ: 色付きの太枠 + Dela Gothic One + 少し傾ける（-7〜-9°）+ かすれ
- レシート: 上端がギザギザ、点線の区切り、等幅の数字、下にバーコード
- マスキングテープ: 黄色 + 黒枠 + 端がギザギザ、少し傾ける
- AI の結果: ミントのクリップボード（上にクリップ）
