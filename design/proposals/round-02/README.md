# Round 02 — オーナーの参考画像の方向（design/refs/owner-reference-01.jpg）

Round 01 は不採用。オーナーの言葉:「クラシックでおしゃれな感じかつ遊び心もある感じ」+ 参考画像「こんなイメージ」。
（いったん考えた D 手帳 / E カード / F 通知表の 3 案は、参考画像が届いたので作らずに破棄）

参考画像から読み取ったこと:
- 暖かいオフホワイトの紙、太い黒の輪郭線 + 黒いずらし影（ネオブルータル / ステッカー）
- 極太の英字見出し（COMMIT OR TREAT / TODAY'S MISSIONS）と黒いピルのタグ
- ゴム印のスタンプ（ミントの PASSED、赤の サボり確定）
- ランキングはレシート（ギザギザの上端・点線・バーコード）、PayPay のオレンジボタン
- 写真にマスキングテープ、AI の結果はミントのクリップボード「カルテ」
- 星のステッカー、イラストのアバター

このラウンド: この方向をそのまま実際の 3 画面（ダッシュボード・提出と AI 検問・理由申告）に当てはめる。1 案。
書体: Archivo Black（英字見出し）+ Dela Gothic One（和文見出し・スタンプ）+ Zen Kaku Gothic New（本文）+ BIZ UDGothic（レシート）+ Klee One（手書きの合言葉）。

## 自分の評価
- 参考画像の要素（太線・ずらし影・スタンプ・レシート・テープ・カルテ）は 3 画面とも再現できた。
- 和文見出し（Dela Gothic One）は小さいサイズだと潰れやすい。ラベルなど小さい見出しは本文書体の太字に切り替える余地あり。
- スタンプは「誰が・どうなったか」がひと目で分かり、ダッシュボードの情報設計としても機能している。
- 写真はサンプル（方眼紙を CSS で描いたもの）。実際はユーザーの写真が入る。
